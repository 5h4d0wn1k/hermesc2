# Security Policy

## Reporting a vulnerability

This project is a security-education and authorised-testing tool. That does not
make it immune to bugs — including bugs that could be misused. Please report any
flaw, safety-gate bypass, or weakness **privately**:

- Open a **private** GitHub security advisory, or
- Email the maintainer (address in `AUTHORS`) describing the issue.

Do **not** create a public issue for a security problem.

## What we ask

- Allow a reasonable remediation window before public disclosure.
- Include reproduction steps and impact.
- Do not weaponise or publish a working exploit for the flaw against third parties.

## Scope

Vulnerabilities in the tool itself, the demo harness, safety gates, or build
configuration. Vulnerabilities in **target** systems your lab uses are out of
scope for this repository — report those through your lab's own responsible
disclosure process.
